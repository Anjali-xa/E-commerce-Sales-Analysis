# E-commerce Sales Analysis

**Author:** Anjali Kshirsagar  
**Tools:** Python, Pandas, Matplotlib, SQL

## Overview
Analyze order revenue, profit, product categories, monthly trends and regional performance.

## Dataset
- File: `data/dataset.csv`
- Rows: 900
- Columns: 9
- This project uses a **purpose-built synthetic dataset** created for portfolio demonstration and reproducible practice. It is not represented as real customer, company, government, or platform data.

## Business questions
Revenue by month; top categories; profit margin; regional contribution.

## Run the analysis
```bash
python -m pip install -r requirements.txt
python analysis.py
```

The script prints key summaries and saves charts in `outputs/`.

## Repository structure
```text
data/dataset.csv
analysis.py
requirements.txt
README.md
```

## Notes
This is a learning portfolio project. Interpret results only within the synthetic sample; do not treat them as real-world market estimates.
